# 能力 Lint 概述

对 TypeScript 项目的**副作用追踪与架构评分**工具。

## 核心概念

- 【能力】：函数对外部世界的影响分类（IO、Impure、Async、Fallible、Mutable）
- 【阻断能力】：声明"已处理"对应能力，阻止向上传播
- 【加权语句数】：按嵌套深度和分支加权的函数体语句数
- 【Pass-through 函数】：自身逻辑极少、主要工作是转发调用的函数
- 【间接税】：函数委托链带来的认知成本
- 【递归组合评分】：新的评分公式，取代 `ws × capCount`

## 工作流

```
扫描项目 → 检测能力 → 传播分析 → 递归评分 → 诊断输出
```

## 评分原理

当前公式 `【加权语句数】 × 【传播能力数】` 存在【评分公式缺陷】。
修复方案为【递归组合评分】：`score = own + Σ(callee.score × DECAY)`。
