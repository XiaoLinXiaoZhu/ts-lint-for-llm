# 阻断能力

阻止对应【能力】向上传播的能力声明。

## 三种阻断能力

- 【HandleAsync】：阻断 Async 传播。函数消化了 callee 的异步性（如 await 后同步返回）。
- 【HandleFallible】：阻断 Fallible 传播。函数处理了 callee 的空值/失败（如提供 fallback 值）。
- 【HandleMutable】：阻断 Mutable 传播。函数隔离了 callee 的变异（如传入拷贝）。

## 特性

- 不计入评分
- 不可自动检测，只能手动声明
- 阻断是单向的：HandleX 只阻断 X，不影响其他能力

## 与 Pass-through 的区别

【Pass-through 函数】通常不声明阻断能力——它们只是转发调用，不发生能力变化。阻断能力用于真正"消化"了副作用的函数。
