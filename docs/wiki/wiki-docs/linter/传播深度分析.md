# 传播深度分析

衡量一个【能力】从"源头"传播到当前函数需要经过多少跳。

## 源头定义

能力 C 的"源头"函数：
- 直接调用外部 API（外部能力声明表匹配）
- 自身代码触发 auto-detect（Async 关键字、nullable 返回等）

## 深度计算

从源头 BFS 向上游传播：
- 源头函数：深度 0
- 直接调用源头者：深度 1
- 调用"调用源头者"者：深度 2
- ...

## ChatFrame-v11 发现

- IO 是唯一有意义传播的能力（最深 7 跳）
- Async/Fallible/Mutable 几乎都是深度 0（auto-detect 使每个持有者都是源头）
- 16 个函数深度 ≥2，最深的是 `produceChatChunks`（深度 7）

## 与递归评分的关系

传播深度分析是【递归组合评分】的补充而非替代：
- 深度分析：衡量"能力离源头有多远"
- 递归评分：衡量"函数间接委托了多少复杂度"

两者结合可完整刻画【间接税】。
