# 4. DFMEA

| 失效模式 | 影响 | 控制 | 责任 F |
| --- | --- | --- | --- |
| 外部 IO 未声明 | 效果传播漏报 | `@effect` + 外部源头测试 | F001 |
| `mutates-input` 仅按类型误报 | 错误阻断 | 基于真实写入的符号分析 | F002 |
| `@handles` 无证据却生效 | 隐藏失败 | `unproven-handling` 阻断 | F003 |
| 调用图传播丢失 | 接口假通过 | 传播闭包测试 | F004 |
| 参数透传被忽略 | 理解成本上升 | audit 高优先级诊断 | F005 |
| CLI 重新实现规则 | 双轨逻辑 | 薄壳边界测试 | F006 |

RPN ≥ 120 或严重度 ≥ 9 的风险必须有回归测试和关闭证据。
