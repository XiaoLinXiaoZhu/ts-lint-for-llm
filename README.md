# lm-linter

TypeScript Effect and interface analysis for model-assisted code quality work.

```bash
bun install
bun run apps/cli/src/main.ts check --tsconfig ./tsconfig.json
bun run apps/cli/src/main.ts audit --tsconfig ./tsconfig.json
```

The product contract lives in [docs/ie/README.md](./docs/ie/README.md).
